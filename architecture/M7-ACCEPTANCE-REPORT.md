# ContractOps M7 验收报告

## 状态

M7 实现已提供自动化证据链。最终实测数字由 GitHub Actions 的
`M7 production-readiness evidence` 任务生成，首个成功运行后从
`contractops-m7-evidence/m7-evidence.md` 原样回填到本报告。

本地环境未安装 Docker，因此不把本机的内存测试速度伪装成服务性能数据。CI 使用真实
FastAPI/Uvicorn 进程、PostgreSQL 16、RLS 应用角色和 Redis，产出 Locust CSV/HTML、
JSON、Markdown 和 API 日志。

## 固定测试剖面

| 项目 | 配置 |
| --- | --- |
| 并发用户 | 20 |
| 启动速率 | 5 用户/秒 |
| 持续时间 | 30 秒 |
| 请求组合 | 合同创建、合同读取、审批待办、审计查询 |
| 通过阈值 | QPS ≥ 10；P95 ≤ 1,000 ms；失败率 ≤ 1% |
| 数据层 | PostgreSQL 16 + 非超级用户 RLS 角色 |
| 模型成本 | 模型辅助关闭，Token 成本为 0 |

## 正确性与故障门禁

| 指标 | 目标 | 自动化证据 |
| --- | ---: | --- |
| 审批陈旧版本冲突拦截率 | 100% | PostgreSQL 审批集成测试 |
| Worker/Redis/通知恢复率 | 100% | M7 故障注入测试 |
| 重复通知率 | 0% | 投递唯一键、重复消费和人工重放测试 |
| 跨租户与越权阻断率 | 100% | API、RLS 和审计安全测试 |
| 恶意 DOCX 阻断 | 100% | 解压大小、条目数、加密和压缩比限制 |
| SSRF 基线阻断 | 100% | 私网解析、凭据和重定向拒绝测试 |

| 指标 | 结果 |

| 请求总数 | 等待首个 M7 CI 产物 |
| QPS | 等待首个 M7 CI 产物 |

所有数字必须同时保留提交 SHA、工作流运行 ID、并发数、持续时间和运行环境。CI 基线只用于
回归比较，不等同于生产容量承诺；上线前应在目标规格预发布环境重复更长时间的稳态和峰值
测试。
