# EduMind 方案迁移说明

原方案计划建设完整的企业知识、RAG、多 Agent 培训和模型网关平台。由于个人项目
范围过大，当前主线已经收缩为：

> **ContractOps：企业合同审查、审批与履约跟踪服务。**

新的项目入口是 [`README-CONTRACTOPS.md`](README-CONTRACTOPS.md)，实施计划见
[`architecture/CONTRACTOPS-IMPLEMENTATION-PLAN.md`](architecture/CONTRACTOPS-IMPLEMENTATION-PLAN.md)。

OpenMAIC 与 Switchyard 代码继续保留，用于演示 UI 和可选模型路由实验，但不再被
描述为 ContractOps 已实现的业务能力。原 EduMind 规划文档保留为迁移指引，避免
旧链接失效。
